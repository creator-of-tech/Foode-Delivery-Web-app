# Foode-Delivery-Web-app
Developed a responsive food-delivery web application using React, React Router, Redux Toolkit and Tailwind CSS, implementing restaurant discovery, dynamic menu browsing, cart management and checkout.
Integrated REST APIs to fetch restaurant and menu data dynamically; implemented reusable components and route-based navigation for restaurant-specific menus.
Implemented Redux Toolkit state management for cart operations and menu caching, reducing redundant API requests when revisiting restaurants.
Built a dynamic checkout flow with quantity management, real-time subtotal calculation, taxes, delivery fees and order summary.
